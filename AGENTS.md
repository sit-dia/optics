# Optics Explorer Agent Guide

## Project Overview

An interactive thin-lens optics simulator for VR/AR education, built for the DIA module at SIT. Deployed at [optics.diaversity.org](https://optics.diaversity.org) via GitHub Pages.

## Tech Stack

- **TypeScript** with strict mode
- **Canvas 2D** for rendering (no external rendering libraries)
- **Vite** for build tooling and dev server
- **Vitest** for unit testing
- **GitHub Pages** for hosting (output to `docs/`)

## Key Directories

```
src/
  main.ts           # Entry point, initializes canvas and UI
  canvas-utils.ts   # Drawing primitives (arrows, lens, rays, labels, glow)
  optics-math.ts    # Thin-lens equation, magnification, image type
  constants.ts      # Colors, default HMD parameters
  types.ts          # TypeScript type definitions
  ui-controls.ts    # Slider and readout UI components
  styles/           # CSS styles
  panels/
    thin-lens.ts    # Main thin-lens simulation panel
docs/               # Production build output (served by GitHub Pages)
tests/              # Vitest test files
```

## Build/Test Commands

```bash
npm install          # Install dependencies
npm run dev          # Start dev server (localhost:5173)
npm run build        # Compile TS + build to docs/ (includes CNAME postbuild)
npm run preview      # Preview production build
npm test             # Run vitest in watch mode
npm run test:run     # Run vitest single-run
```

## Coding Conventions

- TypeScript strict mode
- 2-space indentation, no tabs
- No emojis in code or comments
- Canvas 2D rendering only (no Three.js, no Babylon.js)

## Deployment

- Production build outputs to `docs/` directory
- GitHub Pages serves from `docs/` on the `main` branch
- Custom domain: `optics.diaversity.org` (CNAME auto-generated by postbuild script)
- Push to `main` triggers automatic deployment
